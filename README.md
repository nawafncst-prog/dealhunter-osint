# dealhunter-osint
DealHunter OSINT is an open-source passive intelligence (OSINT) tool designed to automate the discovery of undervalued second-hand items and vehicles across online platforms.

Core Purpose & Functionality
Instead of manually searching multiple classifieds and social media channels, DealHunter OSINT uses customized Google Dorks to scan publicly indexed listings. It extracts product details, compares asking prices against a target fair-market value, and calculates potential profit margins or savings.
